# Customer Churn Prediction

A Machine Learning web application built with **Streamlit** that predicts whether a customer is likely to churn based on customer information.

## 🚀 Live Demo

**Web App:** https://customer-churn-predictes.streamlit.app/

## 📌 Features

* Predict customer churn instantly
* Simple and user-friendly interface
* Real-time predictions
* Machine Learning model integrated with Streamlit
* Fast and responsive web application

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Scikit-learn
* Joblib
* Matplotlib

## 📊 Input Features

The application accepts customer details such as:

* Credit Score
* Geography
* Gender
* Age
* Tenure
* Balance
* Number of Products
* Has Credit Card
* Is Active Member
* Estimated Salary

## 🎯 Output

The model predicts whether the customer is:

* **Likely to Churn**
* **Not Likely to Churn**

## 🤖 Machine Learning

The project uses a trained **Scikit-learn** Machine Learning model saved using **Joblib** and deployed with **Streamlit**.
